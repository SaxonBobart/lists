# Lists

**Tasks, habits, notes, and events in one calm, native iOS app — built on plain text files you own.**

No account. No sign-in. Works offline. Everything is stored as ordinary files in the app's sandbox on your phone.

Status: pre-v1 · iOS-first · local-first · built with SwiftUI on Xcode 27.

## What's in this repo

The iOS app is the only active implementation — `platforms/ios/`, SwiftUI + Swift 6.4, with the Xcode project generated by XcodeGen. Android, Linux, and Windows are parked. If `platforms/android/` is present, treat it as an inactive experiment, not a shipped client.

## Run it

Requirements: Xcode 27+, Swift 6.4, an iOS simulator, and XcodeGen (only needed if project files must be regenerated).

```sh
cd platforms/ios
xcodegen generate     # only if Lists.xcodeproj is missing or project.yml changed
open Lists.xcodeproj
```

Build defaults (project `Lists.xcodeproj`, scheme `Lists`, simulator `iPhone 17 Pro`) live in `.xcodebuildmcp/config.yaml`.

## Tests

`ListsTests` contains focused unit tests plus snapshot regression coverage with swift-snapshot-testing. From `platforms/ios`, run:

```sh
xcodebuild \
  -project Lists.xcodeproj \
  -scheme Lists \
  -testPlan Lists \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  test
```

Use another installed simulator name if needed.

The old XCUITest target was retired 2026-06-13; interactions are verified with focused logic tests plus driven simulator sessions.
