# Lists

**Tasks, habits, notes, and events in one calm, native iOS app — built on plain text files you own.**

No account. No sign-in. Works offline. Everything is stored as ordinary files in the app's sandbox on your phone.

Status: pre-v1 · private · iOS only · built with SwiftUI on Xcode 27 / iOS 27.

## What's in this repo

The iOS app is the only active implementation — `platforms/ios/`, SwiftUI + Swift 6.2, with the Xcode project generated by XcodeGen. Android, Linux, and Windows are parked (old Android code is in git history).

## Run it

Requirements: Xcode 27+, Swift 6.2, an iOS 27 simulator, and XcodeGen (only needed if project files must be regenerated).

```sh
cd platforms/ios
xcodegen generate     # only if Lists.xcodeproj is missing or project.yml changed
open Lists.xcodeproj
```

Build defaults (project `Lists.xcodeproj`, scheme `Lists`, simulator `iPhone 17 Pro`) live in `.xcodebuildmcp/config.yaml`.

## Tests

`ListsTests` — unit tests plus snapshot regression (swift-snapshot-testing); fast, no simulator launch. Run with `/test` in Claude Code, or `xcodebuild -scheme Lists -testPlan Lists test`. The old XCUITest target was retired 2026-06-13; interactions are verified via driven simulator sessions instead.
