# Format

Lists stores user data as markdown files with YAML frontmatter.

Important files:

- `frontmatter.md` - fence and body rules
- `filenames.md` - folder and filename rules
- `reminder.schema.json` - current frontmatter schema, still using old naming
- `list.schema.json` - list metadata schema

The iOS implementation is the current reference. Schema and prose should be realigned with the `Item` model when this contract is next changed.
