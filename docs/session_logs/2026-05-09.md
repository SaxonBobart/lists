## Surprises + gotchas

- **Old simulator container had leftover `.list.yml`** from the archive build using a different schema. Bootstrap errored with `keyNotFound: created_at` because the old files had `created` instead of `created_at`. Wiped `Documents/Lists/` and relaunched — fresh seed worked. Long-term fix: data version + migration shim.
- **`ISO8601DateFormatter` is NOT Sendable** in Swift 6.2; needed `nonisolated(unsafe)`. (Plain `DateFormatter` IS Sendable in current SDK — opposite of what I'd expect.)
- **`SmartList.today` initially used `Calendar.isDateInToday`** which uses wall-clock instead of injected `now`. Fixed to `calendar.isDate(due, inSameDayAs: now)`. Test caught it.
- **No `tap` UI-automation tool** in the XcodeBuildMCP install. Manual checkbox interaction not scripted; persistence verified via the `toggleDonePersists` unit test instead.
